# toukenranbu-event-progress-tracker
DMM刀剣乱舞 遊戲活動追蹤工具


## 關於本專案
本專案為玩家自製的非官方同人工具，協助社群夥伴追蹤「刀劍乱舞」対百鬼夜行系列活動進度（訓練Pt／迎撃Pt、資源消耗、里程碑報酬等）。

- 程式碼部分採 MIT 授權，歡迎參考、自由使用。
- 遊戲內角色名稱、活動名稱、道具名稱等內容版權皆歸原廠 DMM / Nitroplus 所有，本專案與官方無任何關聯。
- 所有進度資料僅儲存在使用者自己瀏覽器的 localStorage，不會上傳到任何伺服器，也不會在使用者之間同步。

## 開發方式
本工具透過與 AI（Claude）協作開發
從發想到可用版本在短時間內完成，過程中根據實際使用需求進行了多輪 UI/UX 調整與修正。
