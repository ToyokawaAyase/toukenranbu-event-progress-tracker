# toukenranbu-event-progress-tracker
DMM刀剣乱舞 遊戲活動追蹤工具 V 2.1


## 關於本專案
本專案為玩家自製的非官方同人工具，協助社群夥伴追蹤「刀劍乱舞」対百鬼夜行系列活動進度（訓練Pt／迎撃Pt、資源消耗、里程碑報酬等）。

- 程式碼部分採 MIT 授權，歡迎參考、自由使用。
- 遊戲內角色名稱、活動名稱、道具名稱等內容版權皆歸原廠 DMM / Nitroplus 所有，本專案與官方無任何關聯。
- 所有進度資料僅儲存在使用者自己瀏覽器的 localStorage，不會上傳到任何伺服器，也不會在使用者之間同步。
- 本工具為非官方同人作品，與 AI 協作開發；使用匿名到訪統計，不蒐集個人資料。

## 開發方式
本工具透過與 AI（Claude）協作開發
從發想到可用版本在短時間內完成，過程中根據實際使用需求進行了多輪 UI/UX 調整與修正。
UI 呈現方式的靈感參考自 [deltarium 玉集め進捗表](https://deltarium.org/tokenranbu/tamaatsume/index.html)，實際程式碼與功能為獨立開發。

## 更新紀錄
V2.1（2026-08-11）
本次更新新增兩個功能頁面、更新既有活動資料，並修復數個已知問題。

新增頁面
1. 鍛刀強化活動（kantou_campaign.html）：追蹤「鬼丸国綱 鍛刀強化キャンペーン」（2026/7/28～8/25）的顯現點數累計進度、鍛刀次數與 all700 配方材料消耗、角色入手狀態；並提供「鍛刀時間反查」功能，依官方公開的參考配方對照表，協助判斷目前鍛刀剩餘時間可能對應到哪些角色。
2. 修行優先順序建議（shugyou_priority.html）：本頁提供「下一隻該送誰」的排序建議清單，內建 7 條可自訂優先順序的判斷規則，使用者可用滑鼠拖曳自行調整規則優先順序，並附修行等級門檻自動過濾。

資料更新
対百鬼夜行迎擊作戰頁面：更新官方已公布的部分里程碑資料（童子切安綱剥落／新刀剣男士獎勵門檻），其餘沿用 2025 年版資料的部分維持標註。
首頁與各頁標題全面中文化，遊戲內道具與角色專有名詞維持日文原文。

介面調整
優化調整全站四個功能頁面加上跨頁導覽列，可直接互相切換，不需每次返回首頁。
首頁與其餘頁面補齊 GoatCounter 追蹤碼。

問題修復
修正部分頁面按鈕點選狀態未反應的問題。
